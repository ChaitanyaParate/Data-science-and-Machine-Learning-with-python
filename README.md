# Breast Cancer Classification

This project focuses on classifying breast cancer tumors as **malignant** or **benign** using machine learning algorithms. It uses standard datasets and popular models to achieve accurate predictions.

## 📂 Project Structure

- **`brest_cancer.ipynb`** – Main Jupyter Notebook containing the entire code for data loading, preprocessing, model building, training, evaluation, and visualization.

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ChaitanyaParate/Data-science-and-Machine-Learning-with-python.git
   cd Data-science-and-Machine-Learning-with-python/Breast_Cancer_Prediction
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Launch the notebook:
   ```bash
   jupyter notebook brest_cancer.ipynb
   ```

## 🧠 Models Used

- **RandomForest Classifier**
- **K-Nearest Neighbors (KNN)**

## 📊 Key Steps

- Data Loading and Exploration
- Data Pre-Preprocessing

## 📈 Results

The models achieve high accuracy on the dataset, with RandomForestClassifier and KNN showing strong performance for cancer classification.

## 📄 Dataset

This project uses a breast cancer dataset downloaded from [Kaggle](https://www.kaggle.com/).
